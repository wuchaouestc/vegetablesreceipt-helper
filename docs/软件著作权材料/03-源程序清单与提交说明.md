## 一、登记对源程序的要求

| 要求 | 本软件的处理 |
| --- | --- |
| 提交前 30 页 + 后 30 页，共 60 页 | 源码共 442 页，满足要求；脚本自动截取前后各 30 页 |
| 每页不少于 50 行（末页除外） | 统一按 50 行/页分页 |
| 页眉标注软件名称与版本号 | 页眉固定为「打单助手软件 V6.3」+ 页码 |
| 不得含第三方库代码 | 只收录本项目自有源码，`__pycache__`、`.venv`、`site-packages` 全部排除 |
| 不得含密钥等敏感信息 | `config_local.py`（真实密钥）被 `.gitignore` 排除，未纳入清单 |

## 三、生成方法

```bash
# 在项目根目录执行，使用项目虚拟环境
.venv/Scripts/python.exe tools/生成软著源码页.py
```

输出到 `docs/软件著作权材料/源程序页/`：

| 文件 | 内容 |
| --- | --- |
| `源程序_全量.txt` | 全部源码，带页眉、页码与分页符（约 1.1 MB） |
| `源程序_前30页.txt` | 前 30 页，对应 1,500 行代码 |
| `源程序_后30页.txt` | 后 30 页，对应末尾 1,500 行代码 |

**转 PDF**：用 Word / WPS 打开对应 txt，页面设置为 A4、纵向、页边距 2 cm，
字体用等宽字体（Consolas 或 宋体 9 号），另存为 PDF。分页符已用 `\f` 插入，
Word 会按页自动分页，无需手工调整。

> 该目录为**派生产物**，已加入 `.gitignore`，不入版本库；需要时重新运行脚本即可。

## 五、提交注意事项

1. **格式**：建议提交 PDF（A4 纵向），文件名 `打单助手软件V6.3-源程序.pdf`。
2. **连续性**：前 30 页必须是源码开篇（`启动器.py` 起），后 30 页必须是源码结尾（测试文件末），
   中间不需连续，但不得跳行、不得省略整段逻辑。
3. **行号**：如登记机构要求行号，可在 Word 中开启「行号」功能，脚本不预置行号以免与页眉冲突。
4. **敏感信息**：本文清单已排除 `config_local.py`；若自行拼装，请确认不含 `AKID` / `sk-` 开头的密钥串。
5. **一致性**：软件说明书中的功能描述、模块名应与源程序一致，本套材料三份文档相互对应。
