## 一、这是什么软件

**打单助手 是一套给蔬菜 / 生鲜农产品批发场景用的**单据识别 + 标签打印**桌面工具。

业务场景很具体：每天有人拿手机拍下供应商发来的采购单（截图或手写单据），过去要靠人眼一行行抄下「品类、编码、斤数」，再一张张打标签。现在把单据图片丢进软件，它自动把图片读成结构化清单，你核对无误后直接出标签。

一句话概括工作流：

```
拍单据照片  →  拖进软件  →  自动识别成清单  →  人工核对/改错  →  一键批量打印标签
```

**核心特点**

| 特点             | 说明                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| **不用手抄**     | 印刷截图和手写单据都支持，手写单据有专门的识别模式                   |
| **规则按客户走** | 7 家客户各有各的格式、编码规则、要跳过的品类，全部预置好，选客户即可 |
| **错不可怕**     | 清单可逐格修改、可撤销、可单独重打某一张                             |
| **有账可查**     | 每一次打印都落盘成台账，对账有依据                                   |
| **离线可查**     | OCR 结果本地缓存，同一张单据不重复识别、不重复付费                   |
| **单文件运行**   | 绿色免安装，拷贝整个文件夹到任何 Windows 电脑就能用                  |

## 二、它替你做了什么

### 2.1 把你从「抄单」里解放出来

拍摄或截取供应商的采购单 → 拖进窗口 → 点「开始识别」：

1. **腾讯云高精度 OCR** 读出图片上的文字和每段文字的**坐标位置**
2. **DeepSeek** 看着 OCR 结果 + 原图，按这套业务规则把文字整理成 JSON 清单
   （品类 / 客户编码 / 斤数 / 单位 / 备注）
3. 本地**自动套用该客户的规则**：该跳过的品类跳过、编码按客户要求截取、备注按要求截断、品类做同义词归一
4. **自动标记可疑项**：认字可疑、斤数可疑的行会高亮，让你重点看

### 2.2 替你防住几种真实的坑

软件内建了多层校验，都是从实际作业里踩出来的：

| 防护           | 解决什么                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| **覆盖核对**   | AI 整段漏掉一个品类 → 对照 OCR 原文查出来                                                                            |
| **交叉核对**   | 各品类斤数合计 vs 单据「数量」列 → 对不上就报警                                                                      |
| **共识投票**   | 仔细模式下跑两遍取共识，避开单次随机抽风                                                                             |
| **重试机制**   | 同一张图连跑 3 次可能得到 `[0, 5, 5]`，那次「0 条」不报错也不告警 —— 软件强制走重试路径                              |
| **改完再重打** | 打印历史存的是「打出去那一刻的值」。改完再点「确认打印」，原版会**静默打回旧值**。补丁用「重打这一张」补上了这头护栏 |

### 2.3 替你记住纸还剩多少

标签纸按卷管理。软件自动累计已打张数，在「设置」→「标签纸」里能看到「这台机器已经打出 N 张」和「每卷多少张」。

用完一卷，点「**我换新卷了**」，计数从零重新开始。

> 打印机本身没有余量传感器，这个数字是**算出来的，不是量出来的** —— 走纸、校准、卡纸这些看不见的消耗不会自动扣。所以算出来的剩余往往比实际偏大，可以按实际情况在「标签纸」设置里预留一点损耗，或者直接凭手感判断。

## 四、功能清单

### 4.1 识单页（核心）

| 功能                    | 说明                                                                      |
| ----------------------- | ------------------------------------------------------------------------- |
| **拖拽加图**            | 把单据图片直接拖进窗口。支持 png / jpg / bmp / webp / tif                 |
| **选择图片…**           | 拖拽不可用时的替代入口                                                    |
| **读客户文件夹**        | 一键把当前客户文件夹里的所有单据加进来                                    |
| **移除选中 / 清空**     | 移除误加的图片                                                            |
| **缩略图预览**          | 点某张图看大图，双击只看它                                                |
| **「出了几条」**        | 每张图右侧实时显示识别出多少条，不用等完才知道                            |
| **仔细模式**            | 手写单据必开；印刷单据疑难时也建议开。跑两遍取共识 + 全量覆盖核对         |
| **开始识别**            | 后台线程执行，界面不卡；进度与日志实时刷新                                |
| **核对清单**            | 识别结果逐行列出，可双击任一格修改                                        |
| **状态标记**            | `❓ 斤数`（斤数可疑）/ `❓ 认字`（认字可疑）/ `已修改` / `已打印`，底色高亮 |
| **筛选**                | 按状态快速过滤：`全部` / `要核对` / `已修改` / `已打印`                   |
| **标签预览**            | 1:1 真实尺寸预览（40×30mm）                                               |
| **确认打印**            | 批量打印当前清单里的所有行                                                |
| **撤销修改**            | 撤销本轮全部改动                                                          |
| **删除这一行**          | 删掉不该打的行                                                            |
| **重新识别**            | 用当前设置重跑                                                            |
| **重打这一张**          | 选中某行后出现，**用清单里现在的值**单独打一张                            |
| **召回上一批**          | 清单空但刚打完一批时出现，把上一批召回来改                                |
| **放大清单 / 还原布局** | 收起图片区，让清单多显示 4~5 行                                           |

### 4.2 历史页

| 功能           | 说明                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 打印历史列表   | **这次开机**打过的每一张：时间 / 客户 / 类型 / 品类 / 客户编码 / 斤数 / 单位 / 备注 / 结果 |
| 重打选中的     | 选中若干行 → 只补打这几张                                                                  |
| 全选           | 批量补打                                                                                   |
| 只看           | 下拉筛选客户，默认「全部客户」                                                             |
| 刷新           | 手动刷新列表                                                                               |
| 打开今天的记录 | 跳到本日的落盘台账文件                                                                     |

> 「历史」页是**内存里的开机内记录**，关掉程序就没了；真正长期留存的台账在 `打单记录/<客户>/` 目录里，格式是 TSV。

> 结果列有两种状态：`重打`（补打成功）/ `中断`（打印过程中被打断）。

> 💡 出纸口少出来几张？→ 「设置」→「标签纸」，把「这台机器已经打出」改小一点。

### 4.3 设置页（8 张卡片）

| 卡片           | 能调什么                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------- |
| **客户**       | 新建 / 复制 / 删除 / 改名档案；逐项配置单据类型、编码规则、备注截断、跳过品类、品类归一表 |
| **标签纸**     | 每卷张数、已打张数、「我换新卷了」重置计数                                                |
| **打印机**     | 打印机名称、硬件 ID（VID / PID）、扫描当前插着的打印机、测试能不能找到                    |
| **界面**       | 字号档（大/中/小）、默认显示标签预览、默认展开运行日志                                    |
| **数据与文件** | 清理识别缓存、打开程序文件夹                                                              |
| **备份与搬家** | 导出设置… / 导入设置… / 恢复出厂设置                                                      |
| **自检**       | 一键体检，出问题先点这里                                                                  |
| **关于**       | 版本号、程序目录、客户档案、设置文件位置                                                  |

> **打印机卡是按硬件 ID 识别的**（VID / PID），不是按驱动名。换打印机就改这两个值 —— 可以点「扫一下现在插着的打印机」自动填。

## 五、首次使用前的准备

### 5.1 运行条件

| 项       | 要求                                                  |
| -------- | ----------------------------------------------------- |
| 操作系统 | Windows 10 / 11，64 位                                |
| 内存     | 4 GB 以上                                             |
| 磁盘     | 约 100 MB（含 `_internal/`）                          |
| 网络     | **需要**（腾讯云 OCR 与 DeepSeek 走公网）             |
| 中文字体 | 微软雅黑 / 黑体 / 宋体 任一（否则标签中文显示成方块） |
| 标签机   | 佳博 GP-1326D 或同类 40×30mm 热敏标签机               |

### 5.2 填密钥（**必做，否则识别不了**）

用记事本打开程序目录下的 **`config.py`**，把三个空字符串填上：

```python
TENCENT_SECRET_ID = "你的腾讯云 SecretId"
TENCENT_SECRET_KEY = "你的腾讯云 SecretKey"
DEEPSEEK_API_KEY = "你的 DeepSeek API Key"
```

> ⚠️ 这个文件里有明文密钥，**别发给别人、别传到网上**。

密钥去哪弄：

- **腾讯云**：控制台 → 访问管理 → API 密钥管理 → 新建密钥。同时确认已开通「通用文字识别（高精度版）」服务
- **DeepSeek**：官网注册后，在「API Keys」页面创建

### 5.3 连接打印机

1. 打印机接好、开机、装好标签纸（宽度 40mm，长度 30mm，走纸方向对准）
2. 打开「设置」→「打印机」
3. 点「**扫一下现在插着的打印机**」自动填入 VID / PID
4. 点「**测试能不能找到**」验证
5. 点「保存打印机设置」

> 软件默认走 **USB 直写**（不经 Windows 打印队列，靠硬件 ID 找设备，速度快）。如果直写不灵，可改用 Windows 驱动通道 —— 前提是装了厂商驱动。

### 5.4 建客户档案

「设置」→「客户」→ 新建。至少要配这几项：

| 字段     | 填什么                                                       |
| -------- | ------------------------------------------------------------ |
| 名称     | 客户名，如「中惠」                                           |
| 文件夹   | 单据存放的文件夹名，与程序目录下的同名文件夹对应             |
| 单据类型 | `printed`（截图）/ `handwritten`（手写）                     |
| 思考强度 | `off`（快省）/ `high`（准慢）                                |
| 编码方式 | `full` 原样 / `nochinese` 砍中文尾巴 / `leadcode` 只取前导码 |
| 备注截断 | `one` 整条截前 3 字 / `split` 按「、」拆两组各截前 3 字      |
| 跳过品类 | 整条不要打的品类，如 `大肉姜(生姜)`、`蒜米`                  |
| 品类归一 | 同义品类合并映射表                                           |

> 📌 **本机已预置 7 家客户**（南波旺、中惠、金勺子、农和、嘉宝、晶美、粒粒香），直接选就能用。详见[第八节](#八七家客户的差异)。

> ⚠️ **改客户名不会自动改文件夹名** —— 软件会明确提示「改了文件夹就读不到老图片了」。改完记得把原文件夹也改名。

### 5.5 跑一次自检

「设置」→「自检」→ 点「开始自检」。它会逐项检查：

| 检查项             | 通过标志                                |
| ------------------ | --------------------------------------- |
| **密钥**           | 「密钥填好了」                          |
| **config.py**      | 「config.py 能读」                      |
| **客户档案**       | 「客户档案读得到 N 家」                 |
| **客户图片文件夹** | 「每家的图片文件夹都在」                |
| **打印机**         | 「找得到打印机（vid_xxxx / pid_xxxx）」 |
| **标签字体**       | 「标签用的字体在 …（msyhbd.ttc）」      |

> 全绿再开始干活，能省掉后面一堆莫名其妙的问题。
> 启动时也会自动跑一次，结果写到程序目录的 `启动自检.txt`。

## 六、日常作业流程

### 6.1 标准七步

```
①  左侧/顶栏选好客户
②  把单据图片拖进窗口（或点【选择图片…】/【读客户文件夹】）
③  手写单据请务必勾上【仔细模式】
④  点【开始识别】，等进度条走完
⑤  在核对清单里核对：
       · ❓斤数 / ❓认字 高亮的行重点看
       · 双击单元格可就地改（Enter 确认，Esc 取消，Tab 跳格）
       · 改错了点【撤销修改】
⑥  点【确认打印】→ 打印
⑦  某张打错了：选中该行 →【重打这一张】（用清单现在的值）
                   或【召回上一批】→ 选中那行 →【重打这一张】
```

### 6.2 核对时重点看什么

| 状态标记 | 含义                   | 你该做什么             |
| -------- | ---------------------- | ---------------------- |
| `❓ 斤数` | 数字识别存疑           | 对照原图看这一格的斤数 |
| `❓ 认字` | 品类名或编码认得不确定 | 对照原图确认字形       |
| `已修改` | 你手动改过             | 扫一眼确认改对了       |
| `已打印` | 这一张已经打过         | 避免重复打             |

> 筛选出来的**仍然是原来的行** —— 行号显示的是它在完整清单里的位置，编辑、删除、打印作用的永远是真正的记录，不会因为筛过就错位。

### 6.3 打错了怎么补救

**场景 A：还没打印就发现清单有错**
直接改，或点「撤销修改」回退，改完再打印。

**场景 B：已经打出来了，发现某张内容不对**

> ⚠️ 这里有个坑：**不要改完再点「确认打印」**。
> 打印历史存的是「打出去那一刻的值」，「确认打印」会拿旧值重打，你改了也不生效。

正确做法：

```
选中打错的那一行  →  点【重打这一张】  →  只补打这一张，用的是清单里现在的值
```

如果是整批都要改：点「召回上一批」把上一批清单召回来 → 改 → 逐张「重打这一张」。

**场景 C：某一行根本不该打**
选中 →「删除这一行」，或右键删除。

### 6.4 常用技巧

| 场景             | 做法                                       |
| ---------------- | ------------------------------------------ |
| 一大批单子要核对 | 点「放大清单 ⤢」收起图片区，多省 4~5 行    |
| 只关心可疑的     | 点筛选条上的「要核对」，列表立刻只剩要看的 |
| 看打印效果       | 勾上「显示预览」，点任意一行看 1:1 标签    |
| 同批单据重复识别 | 不用管，OCR 结果本地缓存，秒出且不重复计费 |
| 想复盘上次打印   | 「历史」页按客户筛选                       |

## 八、七家客户的差异

软件的「智能」很大程度来自**按客户定制规则**。本机预置的 7 家档案差异如下 —— 换客户时这些规则会自动切换，不需要你手工调整。

| 客户       | 单据类型 | 思考强度       | 编码           | 备注截断            | 特殊之处                                                       |
| ---------- | -------- | -------------- | -------------- | ------------------- | -------------------------------------------------------------- |
| **南波旺** | 印刷     | 关（快）       | 不显示         | 整条截 3 字         | 编码列里写的其实是客户名称；跳过「大肉姜(生姜)」「蒜米」       |
| **中惠**   | 印刷     | 关             | 完整           | 整条截 3 字         | 明细形如 `0.5/斤 (1078.4)`，**括号里才是编码**                 |
| **金勺子** | 印刷     | 关             | 完整           | **拆两组各截 3 字** | 有「分组:」和「备注:」两种标注，**分组必须忽略**；跳过「蒜米」 |
| **农和**   | **手写** | **高（准慢）** | 完整           | 整条截 3 字         | 手写竖排 2~3 列，`编码:斤数` 格式，每行独立成条                |
| **嘉宝**   | 印刷     | 关             | 完整           | 整条截 3 字         | 「预订数量」就是要打的斤数；品类自动排序                       |
| **晶美**   | 印刷     | 关             | 完整           | 整条截 3 字         | 两套编码风格 `A23.2` 与 `C1-10` 都原样提取                     |
| **粒粒香** | 印刷     | 关             | **只取前导码** | 整条截 3 字         | 三种单据格式都要认；编码转大写；品类自动排序                   |

> **手写单据（农和）**：务必勾【仔细模式】。手写识别本身准确率有限，仔细模式的两遍共识 + 覆盖核对能把错误率显著压下来。
>
> **金勺子**：如果发现标签备注里出现了不该有的「分组」内容，说明没选对客户档案，或该客户的备注规则被改过。

## 九、标签长什么样

标签规格 **40×30mm @ 203dpi**（渲染为 320×240 像素黑白 1 位位图）。

```
┌──────────────────────────┐
│                          │
│        生  姜            │  ← 品类：尽可能大，自动缩到刚好放得下
│                          │
│        1078.4            │  ← 客户编码（可按客户设置是否打印）
│                          │
│          8  斤           │  ← 斤数：全标签最大的字
│                          │
│              (备注)      │  ← 备注：按客户规则截断
└──────────────────────────┘
```

**为什么用位图而不是打印机内置字体？**

TSPL 内置中文字体只有 24 点 / 48 点两档，且整行必须统一字号 —— 做不到「数字比斤大」，也做不到「长品类刚好撑满不裁切」。位图渲染可以对每个元素单独定字号（精确到 1 点），排版完全自由。

**两种打印通道**

| 通道                | 原理                                                              | 适用                             |
| ------------------- | ----------------------------------------------------------------- | -------------------------------- |
| **USB 直写**        | 通过 Windows `setupapi` 直接把位图数据写进 USB 设备，不经打印队列 | 默认，速度快                     |
| **经 Windows 驱动** | 生成位图后交给 GDI 走标准打印流程                                 | 直写不灵时的备选（需装厂商驱动） |

## 十、常见问题

### 10.1 启动与识别

| 现象                     | 可能原因                             | 怎么办                                                 |
| ------------------------ | ------------------------------------ | ------------------------------------------------------ |
| 双击 exe 没反应          | `_internal/` 目录缺失或损坏          | 重新整目录拷贝，**别只拷 exe**                         |
| 启动报「找不到原版程序」 | `_界面补丁/原版.pyc` 缺失            | 恢复 `_界面补丁/` 目录，或直接运行 `打单助手_旧版.exe` |
| 提示「拖拽功能用不了」   | tkinterdnd2 未正确加载               | 改用【选择图片…】按钮，功能不受影响                    |
| OCR 报「接口报错」       | 密钥错 / 网络不通 / 腾讯云未开通服务 | 「自检」卡跑一次，核对 `config.py`                     |
| OCR 返回空但也不报错     | 图太糊 / 拍歪了 / 不是单据           | 重拍；勾【仔细模式】再试                               |
| 识别结果明显不对         | 没选对客户 / 单据类型判断错          | 检查当前客户是否正确；手写单必须勾仔细模式             |
| 识别特别慢               | 开了仔细模式                         | 印刷单据关掉仔细模式                                   |

### 10.2 打印

| 现象                | 可能原因                                  | 怎么办                                  |
| ------------------- | ----------------------------------------- | --------------------------------------- |
| 标签中文是方块      | 系统缺中文字体                            | 装微软雅黑 / 黑体 / 宋体                |
| 打印没反应          | 打印机不在 ESC/POS 或 TSPL 模式；驱动没装 | 切到「经 Windows 驱动」通道；装厂商驱动 |
| 打印偏移 / 走纸不对 | 标签尺寸与打印机配置不匹配                | 检查打印机媒体设置为 40×30mm            |
| 改了格子但纸上没变  | 用了「确认打印」而不是「重打这一张」      | 见 [6.3](#63-打错了怎么补救)            |
| 剩余张数显示偏大    | 走纸/校准/卡纸等不可见消耗                | 预留一点损耗；或凭手感提前换卷          |

### 10.3 数据与维护

| 现象               | 可能原因               | 怎么办                                                                                             |
| ------------------ | ---------------------- | -------------------------------------------------------------------------------------------------- |
| 想清缓存但怕丢东西 | —                      | 「设置」→「数据与文件」→「清理识别缓存」，清完不影响已识别好的清单，只是下次同样的图要重新识别一遍 |
| 想直接找文件       | —                      | 「设置」→「数据与文件」→「打开程序文件夹」                                                         |
| 换电脑             | —                      | 拷贝整个程序目录 + 重新填 `config.py`（密钥不随备份走）                                            |
| 想备份配置         | —                      | 「设置」→「备份与搬家」→「导出设置…」                                                              |
| 客户档案改乱了     | —                      | 「恢复出厂设置」只清配置，**不动台账和客户图片**                                                   |
| 改名后读不到老图片 | 客户名改了但文件夹没改 | 把原文件夹也改成同名                                                                               |

### 关于打单记录

台账是 **TSV（制表符分隔）**，不是 CSV。这是故意的 —— 用 Excel 打开 CSV 会把 `022.2` 静默变成 `22.2`，前导零一丢，编码就对不上了。

用 Excel 看的正确姿势：**数据 → 从文本导入 → 分隔符选「制表符」→ 列格式选「文本」**。

## 十二、一句话速记

```
选客户 → 拖单据 → 手写单勾仔细模式 → 开始识别
→ 看高亮的行 → 双击改错 → 确认打印
→ 打错了：选中那行 → 重打这一张（别用确认打印！）
```

**三个最该记住的坑**

1. **改完要重打，只能用「重打这一张」** —— 用「确认打印」会打回旧值。
2. **手写单据必须勾仔细模式** —— 否则准确率不够。
3. **`_internal/` 目录绝对不能删** —— 只拷 exe 到别的电脑一定跑不起来。
